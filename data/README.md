# Sample data files for OptiSeats

This folder contains example CSV input files to help get started with the application.

Files
- students.csv — sample list of students with subject enrollments
- rooms.csv — list of rooms and capacities
- exams.csv — scheduled exams (subject, date, time, duration)

How to use
- Replace these example CSVs with real data matching the same column headers.
- The app should read from a configured data/ folder or allow uploading CSVs through the UI.
